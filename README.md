# 量潮影视制作

## 概述

影视制作——AI 短剧（含中长剧）剧本、生成、成片、上架与复盘的全过程管理。

## 目录

- `apps/qtdrama` — 业务入口站（量潮影视）：作品与教学资源
- `data/context` — 影视制作记忆仓：待归位日志与素材 (git submodule → quanttide-context-of-drama-production)
- `docs/tutorial` — 影视制作教程：留存率等制作指标与方法 (git submodule → quanttide-tutorial-of-drama-production)
